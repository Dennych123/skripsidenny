\chapter*{KATA PENGANTAR}
\addcontentsline{toc}{chapter}{KATA PENGANTAR}

Puji dan syukur penulis panjatkan ke hadirat Tuhan Yang Maha Esa atas rahmat dan karunia-Nya sehingga penulis dapat menyelesaikan laporan tugas akhir berjudul \textbf{``Implementasi Protokol FINS pada Sistem HMI Sumber Terbuka Berbasis Web untuk PLC Omron''}.

Laporan ini disusun sebagai salah satu syarat untuk memperoleh gelar \textit{Sarjana Teknik} pada Program Studi Teknik Informatika, Fakultas Komputer, Universitas Bina Nusantara (BINUS University). Penelitian berfokus pada perancangan dan penerapan sistem \textit{Human–Machine Interface} (HMI) berbasis \textit{open source} dengan dukungan protokol \textit{Factory Interface Network Service} (FINS) sehingga dapat terintegrasi dengan \textit{Programmable Logic Controller} (PLC) Omron di lingkungan manufaktur.
