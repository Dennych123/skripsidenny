\begin{abstract}
    This research aims to integrate the \textit{Factory Interface Network Service} (FINS) protocol into the open-source \textit{Human–Machine Interface} (HMI) system FUXA to enable direct communication with Omron \textit{Programmable Logic Controllers} (PLCs). The implementation involved developing a FINS connector module in Node.js for the backend and adding a configuration interface in Angular for the frontend. Experimental results show that the system can perform read and write operations over the FINS protocol with a success rate of 99\% and an average latency of 48\,ms. Therefore, the enhanced FUXA system provides a stable and cost-efficient open-source HMI/SCADA solution compatible with Omron PLCs, supporting industrial automation and digital transformation initiatives.\\[0.2cm]

    \vspace{0.15cm}

    \textbf{Keywords}—FINS, FUXA, HMI, Omron, PLC, Industrial Automation.

\end{abstract}
